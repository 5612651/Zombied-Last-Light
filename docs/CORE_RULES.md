# 核心规则 v1（制作基准）

本文件锁定后续制作的默认规则，来自用户提供的 `PRODUCTION_BRIEF.txt`。

- 产品：Steam 单人斜俯视尸潮射击、章节制养成 Roguelite。
- 一章即一次 Run。第一章为 5 个普通 Stage + 1 个撤离 Boss Stage。
- 首章设计时长：约 30 分钟，正常玩家目标范围 25–35 分钟。普通关卡合计约 24 分钟，Boss / 撤离约 6 分钟。通过目标、战斗与移动构成时长，不使用无事可做的等待凑时长。
- 第一章场景次序：雨夜街道 → 便利店 / 商业区 → 公寓院落 → 地下停车场 → 加油站 → 撤离 Boss。
- 玩家在当前区域内可移动、搜集与战斗；出口触发后旧 Stage 卸载，本局不能回头。通关不回主菜单。
- Stage 标准生命周期：开始 → 战斗 / 目标 → Area Clear → 奖励 → Rogue 三选一 → 开门 → 加载下一 Stage。Boss 结束走 Chapter Clear → 返回基地。
- Rogue、临时 Buff、武器 Mutation 属于本局；死亡或章节完成时清空。
- 最高章节、每关最高评级、货币、蓝图 / 碎片、武器解锁 / 等级 / 星级 / 固有特性、Research、设置与成就属于永久资料。
- 死亡结束当前 Run、回基地；已经结算的永久资源和解锁保留。重新部署从该章第一关开始；检查点重开暂不加入，避免混淆构筑与评级。
- Stage 完成即结算永久奖励，使用运行 ID + Stage ID 防止重复领取。死亡不回滚已结算奖励。
- 局外战斗数值相对于基础强度上限为 +30%；局内 Build 承担主要强度变化。这个上限是可验证的数值约束，不代表精确的最终输出占比。
- 军械箱使用游戏内资源，抽取武器、蓝图 / 碎片、特性和少量资源；需保底和重复转换。当前不接入真实货币、角色卡池或周期限定池。
- 首轮目标模板：清场、生存、启动并守住发电机、摧毁感染巢。其余目标以后在同一接口扩展。
- 完整敌人阵容和六种枪按原清单逐步制作，不通过单纯换颜色冒充玩法差异。
- 第一章完成后组织 5–10 人真实外部试玩，依据反馈决定第二章。不得用自动化通过或虚构回答代替外部反馈。
- Steam Demo 为基地 + 第一章 + 3–4 种武器 + 25–30 强化 + 5 种敌人 + Boss + 军械 / 成长，目标 30–60 分钟总体验。

当前可运行的三关短原型仍用于回归，不代表首章的关卡数或目标时长已经达成。六关内容在正式流程和资产扩展阶段替换。
